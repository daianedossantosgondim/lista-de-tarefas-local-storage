# Lista de Tarefas — Local Storage

Aplicação web para cadastro e organização de tarefas, criada como atividade do Curso Técnico em Computação Gráfica.

## Sobre o projeto

A página permite adicionar tarefas pelo botão ou pela tecla Enter, marcar tarefas como concluídas e removê-las. Os dados são mantidos no `localStorage` do navegador, inclusive após atualizar ou reabrir a página. A interface tem identidade visual floral em tons rosados e se adapta a telas menores.

## Como executar

Deploy na vercel

## Arquivos

- `index.html` — aplicação completa (HTML, CSS e JavaScript).
- `Relatorio_ABNT_Lista_de_Tarefas.docx` — relatório editável da atividade.
- `Relatorio_ABNT_Lista_de_Tarefas.pdf` — versão PDF do relatório.

## Tecnologias e conceitos

HTML5, CSS3 e JavaScript; manipulação do DOM; eventos de formulário; `localStorage`; serialização e leitura com `JSON.stringify` e `JSON.parse`; tratamento de dados inválidos com `try...catch`.
